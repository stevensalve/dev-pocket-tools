Semver & Changelog Helper

Work out the next version, check a range, and draft release notes from commit messages.

Works offline - nothing leaves this device

1. Bump a version

2. Check a range

3. Release notes from commits


        

        

          Uses the current version from step 1. Before 1.0.0 a breaking change moves the minor number, as most projects do. Commits that are
          not in the "type(scope): subject" form are listed as skipped.
